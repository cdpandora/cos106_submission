# Student Portfolio Website

My term project for COS 106 (Introduction to Web Technologies) at MIVA Open University.

## Pages
- Home - name, photo, welcome message and short bio
- About Me - education, career goals, skills, hobbies
- Projects - some projects I have worked on
- Planner - add, complete and delete school tasks (saved in the browser)
- Contact - contact form with JavaScript validation

## Built with
HTML, CSS and JavaScript. No frameworks.

## How to run
Just open `index.html` in a browser
